# POLIMOTOS — Landing Page Premium

Landing page responsiva criada com HTML + CSS + JavaScript puro.

## Estrutura
- `index.html`
- `assets/` — imagens fornecidas para o projeto

## Como usar
Abra `index.html` no navegador ou publique a pasta em qualquer hospedagem estática.

## Personalizações fáceis
- Trocar textos diretamente no `index.html`
- Trocar imagens dentro de `assets/`
- Alterar telefone/WhatsApp nas URLs `wa.me`
- Alterar endereço e horário na seção de contato

A página já inclui:
- Hero premium
- Serviços
- Sobre a empresa
- Manutenção preventiva
- Galeria
- CTA para WhatsApp
- Localização/Google Maps
- Layout responsivo para celular
- Botão flutuante de WhatsApp
